# BETA-7 sekmeli kontrol paneli

Panel: https://ta1fm.github.io/TA1FM-nrf52-Aprs-Tracker-Configurator/BETA/TA1FM_Tracker_Panel_BETA7_Sekmeli_USB_BLE.html

BETA-6 paneli değiştirilmedi.

- Mesajlar: ortak USB/BLE gelen kutusu, gönderim ve ACK, 1/2/3 RF denemesi
- Canlı: BLE cihaz bilgileri, firmware, gelen kutusu RAM kullanımı, GPS, RF, TX, WX TX, son duyulan istasyon
- Ayarlar: USB ayarlar, Smart Beacon, LoRa TX gücü, OLED ve yedekleme. Mevcut BLE kaydetme kilidi Canlı bölümündeki BLE panelinde korunmuştur
- Kayıtlar: USB seri monitör; BLE haberleşme günlüğü Canlı bölümünde bulunur

USB/BLE ortak mesajlaşma için V0.9.26 BETA-7 firmware gereklidir. Eski BETA-6 firmware ile eski BETA-6 panelini kullanın.

JavaScript sözdizimi kontrol edildi, gerçek cihaz/tarayıcı henüz test edilmedi.
